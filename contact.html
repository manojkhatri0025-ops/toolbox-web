How to File an Effective Bug Report

To help our engineering team diagnose and fix client-side issues quickly, please consider including:

  • The exact tool name and URL
  • Your device operating system (Windows, macOS, iOS, Android, Linux)
  • Your browser name and version (e.g. Chrome 122, Firefox 123)
  • The format or size of the file causing issues
  • Any console error messages if accessible
